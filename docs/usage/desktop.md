# 桌面端使用

桌面端以内嵌 WebView 打开学习通页面，并在识别到相应页面后自动注入课程脚本，无需手动打开浏览器控制台。

## 1. 配置模型

打开左侧 **Configuration**，在 API 区域依次设置：

1. **Provider**：模型供应商。
2. **Model**：该供应商下要使用的模型。
3. **API Key**：供应商访问密钥。输入框失焦后会隐藏密钥内容。

点击 **Save** 后，供应商、模型、密钥和课程选项将保存至本地。智能答题说明见[智能答题](ai.md)。

## 2. 调整课程选项

Configuration 的 Course 区域提供以下选项：

- **Persist Session**：保留课程 WebView 的登录会话。
- **Mute Course Webview**：静音课程页面。
- **Lock Playing Speed**：锁定播放速度。
- **Playing Speed**：填写播放速度数值。

修改后同样点击 **Save**。

## 3. 打开课程并启动任务

1. 在右下角课程 WebView 登录学习通。
2. 打开课程和需要处理的章节。
3. 页面加载后，按课程页弹窗提示启动任务。

顶部工具栏提供后退、前进、刷新、返回首页和缩放控制。未识别的网址不会注入课程脚本。

## 4. 查看状态

左下角仪表盘显示课程封面、课程名称、当前章节、任务点和章节完成百分比。离开课程页面后状态会重置，重新进入时会接收新的课程状态。

遇到无法启动、状态不更新或课程类型不兼容时，请先查看[常见问题](../troubleshooting.md)。
